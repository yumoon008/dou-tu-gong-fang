# Image quality fixtures

The two `synthetic-*` PNG files are deterministic test charts generated by
`generate-synthetic-fixtures.ts`. They cover all Mard palette entries, neutral
and skin-tone gradients, high-frequency patterns, diagonal edges, transparency,
and antialiased colored shapes.

The portrait, pet, landscape, and still-life fixtures were generated for this
repository with OpenAI image generation on 2026-08-07. They contain no user
photos, third-party brands, readable text, or downloaded copyrighted assets.
They intentionally cover skin tones, hair, fur, sky, foliage, reflective glass,
hard object boundaries, saturated colors, highlights, and shadows. The committed
JPEG, WebP, and PNG files are the canonical inputs; CI never regenerates or
downloads them.
